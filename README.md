# 🇬🇧 English

## About

**Wavium** is a modern desktop music player designed to deliver a complete, customizable and seamless music experience.

The project aims to bring music playback, video integration, synchronized lyrics and personal music management together in a single application.

Built with simplicity and usability in mind, Wavium aims to give users greater control over how they discover, organize and enjoy their music.

## Features

Wavium is being developed with the following features in mind:

- 🎧 **Music Playback** – Play and manage your music.
- 🎬 **Music Videos** – Watch official music videos within the application.
- 🎤 **Synchronized Lyrics** – Follow song lyrics in real time.
- 🎵 **Music Library** – Organize and access your music.
- 📂 **Playlists** – Create, import and manage playlists.
- ❤️ **Favorites** – Save your favorite tracks.
- 🕘 **Listening History** – Keep track of previously played songs.
- 🔎 **Music Search** – Search for songs, albums and artists.
- ⬇️ **Download Manager** – Download supported songs, albums and playlists.
- 🔀 **Playback Controls** – Shuffle, repeat, skip and control playback.
- 📊 **Statistics** – Explore your listening habits.
- 👤 **Personal Accounts** – Local user accounts with individual settings.
- ⚙️ **Customization** – Personalize your application experience.
- 🌍 **Multilingual Interface** – Support for multiple languages.

*Features are subject to change during development. Not all features are currently available.*

## Interface

Wavium features a clean, minimalist interface with a dark visual identity.

The application is organized into the following sections:

| Section | Description |
|---|---|
| Home | Main dashboard and music discovery |
| Search | Find songs, albums and artists |
| Favorites | Your saved music |
| Queue | Manage upcoming tracks |
| History | Previously played music |
| Imports | Manage imported content |
| Import Playlist | Import external playlists |
| Settings | Customize your experience |

## Technology

- **C# / .NET** – Application development.
- **SQLite** – Local data storage.
- **LibVLC** – Multimedia playback.
- **Windows** – Initial target platform.

The architecture is intended to support future expansion to additional operating systems.

## Project Goals

Wavium aims to deliver:

- A clean and professional user experience.
- No intrusive advertising.
- Greater personalization and user control.
- Efficient resource usage.
- Reliable music and video playback.
- Continuous improvements and new features.

## Development

Wavium is currently under active development.

The project is being built from the ground up, with an emphasis on creating a stable, polished and fully functional desktop application.

# 🇪🇸 Español

## Acerca de

**Wavium** es un reproductor de música moderno para escritorio, diseñado para ofrecer una experiencia musical completa, personalizable y fluida.

El proyecto busca reunir en una sola aplicación la reproducción de música, la integración de vídeos musicales, las letras sincronizadas y la gestión de bibliotecas musicales personales.

Desarrollado con un enfoque en la sencillez y la comodidad, Wavium pretende ofrecer a los usuarios un mayor control sobre cómo descubren, organizan y disfrutan de su música.

## Características

Wavium está siendo desarrollado con las siguientes funcionalidades:

- 🎧 **Reproducción de música** – Reproduce y gestiona tu música.
- 🎬 **Vídeos musicales** – Visualiza videoclips oficiales desde la aplicación.
- 🎤 **Letras sincronizadas** – Sigue las letras de las canciones en tiempo real.
- 🎵 **Biblioteca musical** – Organiza y accede a tu música.
- 📂 **Listas de reproducción** – Crea, importa y gestiona playlists.
- ❤️ **Favoritos** – Guarda tus canciones preferidas.
- 🕘 **Historial de reproducción** – Consulta las canciones que has escuchado.
- 🔎 **Buscador musical** – Busca canciones, álbumes y artistas.
- ⬇️ **Gestor de descargas** – Descarga canciones, álbumes y listas compatibles.
- 🔀 **Controles de reproducción** – Reproducción aleatoria, repetición, anterior y siguiente.
- 📊 **Estadísticas** – Consulta tus hábitos musicales.
- 👤 **Cuentas personales** – Cuentas locales con ajustes individuales.
